# Commands & Colors: Napoleonics — Epic & Grand Battles (VASSAL module)

Standalone module for the larger-format Epic and Grand Battle scenarios (Expansions #6 and #7, plus unofficial scenarios from commandsandcolors.net).

* `dist/` is the module, unpacked: one commit per release, tagged `v<version>`, taken from the [Vassal Module Library](https://vassalengine.org/library/projects/Commands__Colors_Napoleonics_EPIC__Grand_Battles).
* `extensions/` holds published extensions (Epic fan scenarios for v2).
* Branches: `main` follows the current version (v4); `v2` ends at 2.3.4.
* Build with `./mvnw package` (module written to `target/`).

The standard-size module is in [ccnapoleonics](https://github.com/RiverWanderer-Vassal/ccnapoleonics).
